# Анкеты и резюме

Сюда складываются профили соискателей для python-only радара.

## Как устроено

- `Универсальная анкета/` — HTML-форма. Её заполняет соискатель.
- `Анкета_Имя/` — появляется после кнопки «Сохранить результат». Сюда же кладут PDF резюме.

Папки `Анкета_*` в git не коммитятся (персональные данные и резюме).

## Как открыть форму

Запустите `Универсальная анкета/Открыть анкету.bat` — откроется браузер и локальный сервер сохранения.
