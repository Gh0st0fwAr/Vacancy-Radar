# Универсальная анкета VacancyRadar

1. Дважды щёлкните `Открыть анкету.bat`.
2. Заполните форму в браузере.
3. Нажмите **Сохранить результат**.
4. Появится папка `анкеты и резюме/Анкета_ВашеИмя/` с файлом `анкета.txt`.
5. Положите туда же PDF резюме.

Без bat форма откроется, но браузер не сможет сам создать папку на диске — нужен этот маленький сервер (только стандартный Python).
