# Vacancy Radar

**Ветка `python-only`:** поиск и очередь как в основной версии (Clear Check, хоткей, статистика HH, статус писем), но скоринг — Python rules по анкете, письма — локальный шаблон. Cursor SDK выключен (`python_only=true`).

Профиль тестировщика: откройте `анкеты и резюме/Универсальная анкета/Открыть анкету.bat`, сохраните результат в `анкеты и резюме/Анкета_Имя/`, положите туда PDF резюме. Пока импорт в радар ручной (через агента Cursor). Старт конфига: `data/config.example.json`.

Небольшая утилита для автоматического поиска вакансий на [hh.ru](https://hh.ru), скоринга, очереди «горячих» карточек и подготовки сопроводительных писем. Репозиторий: [Gh0st0fwAr/Vacancy-Radar](https://github.com/Gh0st0fwAr/Vacancy-Radar).



**Требования:** Windows, Python 3.9+, Google Chrome, [Cursor](https://cursor.com) (для генерации писем через Cursor SDK; без ключа письма собираются локальным шаблоном).



Версия: **v0.6.2**



---



## Возможности



- Периодический поиск удалённых вакансий Vue / Nuxt на hh.ru через Chrome DevTools (CDP)

- Скоринг по полному тексту вакансии; в очередь попадают карточки с порогом (по умолчанию ≥ 70%)

- Глобальный хоткей (по умолчанию \Ctrl+Alt+Q\): следующая вакансия → вкладка в Chrome + письмо в буфер

- Сопроводительные: портфолио + контакты + текст; служебный скоринг в письмо не попадает

- Статистика откликов HH + звуковые/tray-алерты при росте приглашений, собеседований, непрочитанных

- Графитовый UI, крупный шрифт, подсветка активного указателя

## Быстрый старт



1. Клонировать репозиторий и перейти в папку проекта.

2. Установить зависимости:



\\ash

pip install -r requirements.txt

\

3. (Опционально, для писем через Cursor SDK.) В каталоге \cursor_bridge\:



\\ash

npm install

\

4. Создать конфиг:



\\ash

copy data\\config.example.json data\\config.json

\

Откройте \data/config.json\ и при необходимости укажите \cursor_api_key\ (Dashboard → Integrations на cursor.com). **Не коммитьте ключ в git.**



5. Запуск:



\\ash

Start VacancyRadar.bat

\

или



\\ash

python main.py

\

6. В окне Radar нажмите **«Войти в HH / Открыть Chrome»** и залогиньтесь в hh.ru в профиле Chrome Radar (порт отладки \9222\).

7. Нажмите **«Проверить связь»** — должно быть «Связь OK».

8. **«Искать сейчас»** или дождитесь автопоиска по таймеру.

## Интерфейс



Окно делится на две колонки (разделитель можно тянуть). Правая колонка прокручивается целиком.



### Левая колонка — очередь



| Элемент | Назначение |

|--------|------------|

| Список вакансий | Карточки со score ≥ порога. Новые — яркие; открытые — \✓\; откликнутые — \★\ зелёным; скип — жёлтым \⏭\; активная (указатель) — зелёный \→\, крупный шрифт |

| **Открыть выбранную** | Открыть текущую строку в Chrome + письмо в буфер |

| **Откликнулся** | Пометить как applied (зелёный статус) |

| **Скип** | Пропустить (жёлтый); хоткей больше не открывает эту карточку |

| **Удалить** | Убрать из очереди навсегда (в поиск не вернётся) |



### Правая колонка — управление и карточка



**Верхний ряд кнопок**



| Кнопка | Действие |

|--------|----------|

| Войти в HH / Открыть Chrome | Запуск Chrome с профилем Radar и remote debugging |

| Проверить связь | Проверка порта CDP |

| Искать сейчас | Внеочередной поиск |

| Пересобрать письма | Перегенерация сопроводительных |

| Обновить статистику | Съём счётчиков с hh.ru |



**Блок «Статистика HH»** — ожидание, всего откликов, приглашения, собеседования, отказы, непрочитанные, просмотры/показы резюме, сколько новых в очереди, время обновления.



**Гайды** — краткие подсказки по статистике и хоткею.



**Хоткей** — текущая комбинация крупным бейджем; назначение, проверка, сброс на \Ctrl+Alt+Q\.



**Опции**



- Звук при новой вакансии (тройной писк)

- DND — без звука

- Сворачивать предыдущее окно по хоткею (не трогает Chrome / сам Radar / fullscreen)



**Карточка вакансии** — title, company, URL, score, ЗП, статус, «почему» (только для вас, не в письмо).



**Сопроводительное** — текст письма + **«Скопировать письмо»**.



**Лог** — события: поиск, Chrome OK за N мс, алерты, готовность письма.



**Трей** — Radar может жить в трее; выход — через меню трея.

## Как пользоваться (типовой сценарий)



1. Запустите Radar и залогиньтесь в Chrome Radar.

2. Дождитесь поиска или нажмите **«Искать сейчас»**. При новых карточках — тройной писк (если звук включён).

3. Нажмите хоткей (\Ctrl+Alt+Q\):

   - один писк — хоткей услышан;

   - в списке сразу зелёный указатель \→\ и превью;

   - вкладка вакансии в Chrome (обычно десятки–сотни мс);

   - если письмо уже есть — оно в буфере (Ctrl+V в форме отклика на hh.ru);

   - если письмо ещё генерируется — позже **двойной писк**, и текст попадёт в буфер.

4. На hh.ru сами нажмите «Откликнуться» и вставьте письмо из буфера. Автоклик «Откликнуться» отключён.

5. В Radar отметьте **Откликнулся** / **Скип** / **Удалить**.

6. Повторный хоткей двигает указатель на **следующую** подходящую вакансию.



### Звуки



| Сигнал | Смысл |

|--------|--------|

| 1 писк | Хоткей сработал |

| 2 писка | Письмо готово и в буфере |

| 3 писка | Появились новые вакансии в очереди |

| 6 писков + toast | Активность работодателя (рост приглашений / собесов / непрочитанных в чате) |

## Конфигурация (\data/config.json\)



| Ключ | Смысл |

|------|--------|

| \search_interval_min\ | Интервал автопоиска (мин) |

| \stats_interval_min\ | Интервал статистики (мин) |

| \score_threshold\ | Порог попадания в очередь |

| \hotkey\ | Глобальный хоткей |

| \hh_search_url\ | URL поиска hh.ru |

| \salary_floor\ / \salary_target\ | Ориентиры по ЗП для скоринга |

| \deep_score\ | Скоринг по полной странице вакансии |

| \cover_letter_via_cursor\ | Письма через Cursor SDK |

| \cursor_api_key\ | Ключ API (секретно) |

| \cursor_model\ | Модель Cursor |

| \chrome_debug_port\ | Порт CDP (по умолчанию 9222) |

| \sound_enabled\ / \dnd\ | Звук / тихий режим |



Пример без секретов: \data/config.example.json\.

## Важно



- Нужен отдельный профиль Chrome Radar с \--remote-debugging-port\ и \--remote-allow-origins=*\.

- Не закрывайте этот Chrome во время работы поиска/статистики.

- Ключи API, \chrome_profile/\, живая очередь и логи в git не коммитятся (см. \.gitignore\).

- Утилита заточена под удалённый Vue/Nuxt-поиск; URL поиска меняйте под себя в конфиге.
