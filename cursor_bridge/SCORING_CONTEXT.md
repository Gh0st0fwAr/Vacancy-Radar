# Контекст скоринга для Cursor SDK и IDE (без жёстких Python-формул)

Задача Cursor: оценить FIT вакансии к кандидату **по смыслу**, опираясь на переданный контекст.
Не копируй балльную схему `radar/scorer.py` (+20 remote, +25 Vue и т.п.). Скоринг — твоё суждение по профилю.

Калибровка: эталон агента кругов (`Проверочный круг вакансий.md`, 17.08.2026). Цель — ±6 пунктов к баллу агента и тот же `accept` относительно порога 70. Не раздувай score до threshold.

## Обязательный контекст кандидата

1. Полный текст резюме из **cvddv.pdf** (в payload / блоке CANDIDATE).
2. Портфолио (демо, направление стека Vue) — считать частью профиля:
   - https://gh0st0fwar.github.io/
   - https://Gh0st0fwAr.github.io/  (тот же сайт; учитывай при оценке)
3. GitHub: https://github.com/Gh0st0fwAr
4. NMS-выдержка в блоке CANDIDATE (коммерческая правда по стеку продакшена).

Не клонируй исходники портфолио как proof of skill. Не отказывай в скоре, если URL недоступны онлайн — текст резюме и ссылки уже в контексте.

## Якорь — шапка резюме

`Frontend Developer (Vue 3, TypeScript) · Middle`.

- Frontend Developer — плюс к FE-ролям; минус к PHP/Node-first fullstack, QA, TL.
- Vue 3 — главный плюс, если Vue в названии или ядре стека.
- TypeScript — плюс, если TS в требованиях; отсутствие TS не штраф.
- Middle — плюс к Middle/Junior+; **Senior/Lead в заголовке вакансии = минус 8–12, не ноль**, если стек Vue.
- Нет Nuxt / React / GraphQL в шапке: «уверенный Nuxt» — минус, но не ноль; React/GraphQL как ядро — сильно вниз.

## Ориентиры профиля (не формулы)

- Middle frontend, 6+ лет Vue; Nuxt — Junior / рост, без завышения.
- Предпочтение: удалёнка; ориентир ЗП ~160k (до ~200k обсуждаемо). Вилка 100–150 — минус, но не авто-reject, если стек Vue 3 + TS.
- Сильные стороны: data-heavy SPA, Vue 2→3, TypeScript, Pinia/Vuex, REST, сложные UI.
- Слабее / честно: чистый React/Angular без Vue; тяжёлый бэкенд без фронта Vue.

## Калибровка accept (порог очереди 70)

`accept=true` только при genuine FIT, обычно score ≥ 70. Не поднимай 68 до 70 «чтобы прошло».

**Должны проходить (ориентиры агента, не заучивай ID):**
- Vue в названии, удалёнка, SPA/Pinia/TS — высокий 80-е (пример уровня: LAB Vue ~88).
- Vue/Nuxt FE без бэкенда как половины роли — 80-е, даже если Nuxt «уверенный» (ИдаПроджект ~86, 585GOLD ~84, STARTRIBE ~80).
- Senior Vue.js при сильном Vue-ядре — 74–78, не 100 (Evrone ~78). Штраф за Senior, не отказ.
- Senior Vue 3 + микрозаймы/SPA — ~76 (Займиго).
- Vue/TS Middle при вилке ниже ориентира — ~74 (GetMeBack).
- Senior fullstack Node/Vue 3, Vue в названии, удалёнка — ~72, на грани.
- Fullstack Node/Nuxt/Vue 3, Vue 3+TS в названии — ровно ~70, нижняя граница.

**Не должны проходить (`accept=false`, 55–68):**
- PHP/Laravel/Symfony/Nest как **половина роли**, даже если Vue есть в скобках: 60–68.
- React или Vue + Web3 / не Vue-ядро: ~55.
- Не возвращай Ruby/Golang/AngularJS/AppSec ≥70 — это ложный hybrid, не FIT.

«Уверенный Nuxt» = минус, но Vue 3 + TS + удалёнка всё ещё может быть 74–86.

## Ответ

Только JSON: {"score":0-100,"accept":true|false,"reasons":["…"]}
reasons: 2–6 коротких пунктов, почему fit / не fit.
