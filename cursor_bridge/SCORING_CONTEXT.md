# Контекст скоринга для Cursor SDK и IDE (без жёстких Python-формул)

Задача Cursor: оценить FIT вакансии к кандидату **по смыслу**, опираясь на переданный контекст.
Не копируй балльную схему `radar/scorer.py` (+20 remote, +25 Vue и т.п.). Скоринг — твоё суждение по профилю.

## Обязательный контекст кандидата

1. Полный текст резюме из **cvddv.pdf** (в payload / блоке CANDIDATE).
2. Портфолио (демо, направление стека Vue) — считать частью профиля:
   - https://gh0st0fwar.github.io/
   - https://Gh0st0fwAr.github.io/  (тот же сайт; учитывай при оценке)
3. GitHub: https://github.com/Gh0st0fwAr
4. NMS-выдержка в блоке CANDIDATE (коммерческая правда по стеку продакшена).

Не клонируй исходники портфолио как proof of skill. Не отказывай в скоре, если URL недоступны онлайн — текст резюме и ссылки уже в контексте.

## Ориентиры профиля (не формулы)

- Middle frontend, 6+ лет Vue; Nuxt — Junior / рост, без завышения.
- Предпочтение: удалёнка; ориентир ЗП ~160k (до ~200k обсуждаемо).
- Сильные стороны: data-heavy SPA, Vue 2→3, TypeScript, Pinia/Vuex, REST, сложные UI.
- Слабее / честно: чистый React/Angular без Vue; тяжёлый бэкенд без фронта Vue.

Решай accept/score сам по соответствию вакансии этому контексту. Порог очереди передаётся отдельно (threshold) — если accept=true, score обычно ≥ threshold.

## Ответ

Только JSON: {"score":0-100,"accept":true|false,"reasons":["…"]}
reasons: 2–6 коротких пунктов, почему fit / не fit.
