АНКЕТА ПОЛЬЗОВАТЕЛЯ VacancyRadar (ветка python-only)
============================================================
Удобнее заполнять HTML-форму:
  анкеты и резюме/Универсальная анкета/Открыть анкету.bat

Ниже — тот же список вопросов текстом, если форма недоступна.

Назначение: заполнить ответы и перенести их в data/config.json
(и при необходимости в hh_search_url / правила скоринга), чтобы
искать вакансии в ДРУГОЙ сфере без Cursor — только Python.

Режим ветки (входные условия, уже зафиксированы):
- Поиск вакансий: Python (Chrome CDP / локальная логика радара)
- Скоринг: только Python (rules), без Cursor SDK
- Сопроводительное: универсальный локальный шаблон по резюме/профилю

Как пользоваться:
1) Ответьте на пункты ниже.
2) Внесите значения в config.json (ключ указан в конце каждого пункта, если есть).
3) Положите резюме PDF рядом с проектом (см. п. про резюме).
4) Перезапустите VacancyRadar.
